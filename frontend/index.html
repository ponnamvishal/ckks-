Encrypted Keyword Search (SSE)

Upload dataset, encrypt keywords, and search without revealing search terms.

Step 1: Upload Dataset

Upload a CSV file with patient/record data. Example: hospital_data.csv with columns like Name, Age, Condition, etc.

Step 2: Encrypt

Select which column contains keywords to search (e.g., Condition, Disease, Diagnosis).

Step 3: Keyword Search

Search for records by keyword (e.g., "cancer", "diabetes", "heart disease").

Step 4: (Keyword Encrypt)

Search keyword is encrypted before sending to server.

Step 5: Encrypted Result

Server searches encrypted index and returns encrypted results.

Step 6: Decrypt

Decrypt the search results to see matching records.

Step 7: Table Form Result

View matching records in table format.
